# Smart Data Encoder and Decoder

## Project Description
This project is a Smart Data Encoder and Decoder developed using HTML, CSS, and JavaScript.

The system converts category names into binary codes (Encoding) and converts binary codes back into category names (Decoding). It also detects invalid binary codes.

## Features
- Encode category into binary code
- Decode binary code into category
- Manual binary code decoding
- Reset function
- Truth Table
- Test Cases
- Synthetic Dataset

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download the project.
2. Open index.html in a web browser.
3. Select a category and click Encode.
4. Click Decode or enter a binary code manually.
